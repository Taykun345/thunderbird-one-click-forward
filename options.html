Bulk Forward Settings

Configure forwarding targets and batch behavior.

How to use:

Bulk forward (multiple emails):
1. Select emails in your inbox message list
2. Right-click on the selected emails → choose "Bulk Forward Selected"
3. Pick a forwarding target from the popup → all emails are forwarded inline automatically

Alternative ways to trigger bulk forward:
• Keyboard shortcut: Ctrl+Shift+F - forwards all selected emails using the first configuration below. Opens the confirmation popup unless confirmation is turned off below; a configuration that deletes permanently always asks.
• Toolbar button: If not visible, right-click the Thunderbird toolbar → "Customize Toolbar" and drag the Bulk Forward icon in
• Alt+Click the toolbar button - same as Ctrl+Shift+F

Single email (message reader):
When viewing a single email, use the small forward button in the message header area to quick-forward just that email.

Note: When multiple emails are selected, Thunderbird enters a summary view where the toolbar may be limited. The right-click context menu and Ctrl+Shift+F shortcut are the most reliable methods for bulk forwarding.

Forwarding Configurations

Each configuration defines a target: recipients, sender identity, forward type, and what to do after forwarding.
Recipients: one per line. Use Name <address> syntax or plain email addresses.

Batch Settings

Minimum 500ms. Higher values prevent SMTP throttling when forwarding many emails. Default: 1500ms.
